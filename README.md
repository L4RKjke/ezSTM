## 🚀 Как прошить контроллер

1. Подключите контроллер к компьютеру по **USB**.
2. Устройство в **режим DFU** перейдет автоматически после начала операции.
3. Запустите `ezSTM.exe`.
4. Выберите файл прошивки.
5. При необходимости включите дополнительные опции — их описание приведено ниже.
6. Запустите операцию и дождитесь сообщения о завершении.
7. После успешной записи перезагрузите контроллер.

## 🚀 Как считать прошивку с контроллера

1. Подключите контроллер к компьютеру по **USB**.
2. Перейдите во вкладку **Считать прошивку**
3. Выберете место для файла прошивки
4. Нажмите кнопку **Считать** и дождитесь сообщения о завершении.
<img width="1920" height="1126" alt="Group 2" src="https://github.com/user-attachments/assets/36a723b6-c724-4e4b-bfab-0dbe13088f6f" />


> [!WARNING]
> Не отключайте USB и не прерывайте работу программы во время прошивки.

## ⚙️ Дополнительные опции

1. Колибовка аксилерометра
2. Полное стирание чипа для снятия защиты
3. Запись имен после успешной прошивки

> [!CAUTION]
> Перед полным стиранием сохраните нужные данные: содержимое Flash-памяти будет удалено.

## 🔧 Если устройство не обнаружено

Проверьте:

- **USB-кабель** — он должен поддерживать передачу данных, а не только зарядку.
- **Подключение** — попробуйте другой USB-порт.
- **Драйвер** — убедитесь, что необходимый драйвер установлен.
