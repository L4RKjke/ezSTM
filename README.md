## 🚀 Как прошить контроллер

1. Подключите контроллер к компьютеру по **USB**.
2. Переведите устройство в **режим DFU**.
3. Запустите `ezSTM.exe`.
4. Выберите файл прошивки.
5. При необходимости включите дополнительные опции — их описание приведено ниже.
6. Запустите операцию и дождитесь сообщения о завершении.
7. После успешной записи перезагрузите контроллер.

> [!WARNING]
> Не отключайте USB и не прерывайте работу программы во время прошивки.

## 🔧 Если устройство не обнаружено

Проверьте:

- **USB-кабель** — он должен поддерживать передачу данных, а не только зарядку.
- **Подключение** — попробуйте другой USB-порт.
- **Драйвер** — убедитесь, что необходимый драйвер установлен.
- **Режим DFU** — убедитесь, что контроллер действительно переведён в этот режим.
