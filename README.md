# ezSTM
Инструмент для прошивки

[**Скачать последнюю версию `ezSTM.exe`**](https://github.com/L4RKjke/ezSTM/releases/latest/download/ezSTM.exe)

Все опубликованные версии доступны в разделе [Releases](https://github.com/L4RKjke/ezSTM/releases).

1. Подключите контроллер к компьютеру по USB и переведите его в режим DFU.
2. Запустите ezSTM.exe.
3. Выберите файл прошивки.
4. При необходимости включите дополнительные опции:
   – Калибровка — если она требуется.
   – Полное стирание чипа — удаляет содержимое Flash. Используйте только при необходимости.
5. Запустите операцию и дождитесь сообщения о завершении. Не отключайте USB во время работы.
6. После успешной записи перезагрузите контроллер.

Важно: перед стиранием сохраните нужные данные. Если устройство не обнаружено, проверьте USB-кабель, драйвер и режим DFU.
