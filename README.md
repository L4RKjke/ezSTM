## :spiral_notepad: Как прошить контроллер

1. Подключите контроллер к компьютеру по **USB**.
2. Запустите `ezSTM.exe`.
3. Устройство в **режим DFU** перейдет автоматически после начала операции.
4. Выберите файл прошивки.
5. При необходимости включите дополнительные опции — их описание приведено ниже.
6. Запустите операцию и дождитесь сообщения о завершении.
7. После успешной записи перезагрузите контроллер.


## :spiral_notepad: Как считать прошивку с контроллера

1. Подключите контроллер к компьютеру по **USB**.
2. Перейдите во вкладку **записать прошивку**
3. Выберете место для файла прошивки
4. Запустите операцию и дождитесь сообщения о завершении.
5. После успешной записи перезагрузите контроллер.
>

> [!WARNING]
> Не отключайте USB и не прерывайте работу программы во время прошивки.
