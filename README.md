# ezSTM

Простой инструмент для прошивки контроллеров по USB.

[**Скачать последнюю версию `ezSTM.exe`**](https://github.com/L4RKjke/ezSTM/releases/latest/download/ezSTM.exe)  


## :spiral_notepad: Как записать прошивку на контроллер

1. Подключите контроллер к компьютеру по **USB**.
2. Запустите `ezSTM.exe`.
3. Устройство в **режим DFU** перейдет автоматически после начала операции.
4. Выберите файл прошивки.
5. При необходимости включите дополнительные опции — их описание приведено ниже.
6. Запустите операцию и дождитесь сообщения о завершении.
7. После успешной записи можете отключить FC.


## :spiral_notepad: Как прочитать прошивку с контроллера

1. Подключите контроллер к компьютеру по **USB**.
2. Перейдите во вкладку **Прочитать**
3. Выберете место для файла прошивки
4. Запустите операцию и дождитесь сообщения о завершении.
5. После успешной записи можете отключить FC.


## ⚙️ Дополнительные опции

1. Калибровка акселерометра
2. Полное стирание чипа для снятия защиты
3. Запись имен после успешной прошивки
4. Правила автоматического именованиям - правила будут описаны ниже.

### Правила автоматического именования

Формулы в полях имени автоматически изменяют имя при каждой записи:

- `*` — пропускает один символ.
- `+N` или `-N` — увеличивает или уменьшает следующее число на N.

**Пример:** `E21-540 | ****+1` → `E21-541` → `E21-542` → …

Если формула неприменима, имя остаётся без изменений
